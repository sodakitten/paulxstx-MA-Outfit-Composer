## ✨ 機能

| 🎽 **スーパースイッチグループ** | 衣装全体（服A/B/C、髪型、体型など）のワンクリック切替。各オプションに個別のオブジェクトとサブレベルクローズメニューを紐付け可能 |

| 💾 **設定バックアップ/復元** | ワンクリックJSONエクスポートでアップグレード前の安全なバックアップ。相対パスでオブジェクト参照を復元 |
| 🔍 **競合検出** | 重複パラメータ名、空オブジェクト、複数スイッチによる競合、既存MAコンポーネントとの衝突を自動検出 |
| ⚡ **パフォーマンス最適化** | Inspectorの毎フレーム更新なし、生成プログレスバー、Parameter Driver Copyによる状態爆発防止 |
| 📁 **アバター別出力** | 各アバターの生成アセットを独立フォルダに保存 — クロスコンタミネーションなし |
| 🛡️ **安全＆オフライン** | 純粋なローカルツール。ネットワーク通信なし、リモート実行なし、隠蔽ロジックなし |

## 📦 インストール

### 手動インストール

1. 最新リリースから `com.paulxstx.last-op-outfit-cn.zip` をダウンロード
2. Unityプロジェクトの `Packages/` フォルダに解凍
3. または Unity Package Manager → Add package from disk → `package.json` を選択

### 依存関係

| 依存 | 最小バージョン |
|------|----------------|
| Unity | 2022.3 |
| VRChat SDK3 — Avatars | 3.x |
| [Modular Avatar](https://modular-avatar.nadena.dev/) | 1.x |

> これらはVRChatアバタープロジェクトに事前にインストールしておく必要があります。

## 🚀 クイックスタート

### 1. コンポーザーを追加

アバタールートを選択し、以下のいずれかの方法で追加：

- メニューバー → `Tools/Paulxstx 换装/给选中角色添加换装生成器`
- ヒエラルキー右クリック → `Paulxstx 换装/添加换装生成器`
- または `添加并生成菜单` で追加とビルドを一度に実行

### 2. 衣装とミックスを設定

Inspectorで：

- **スーパースイッチグループリスト**: 衣装、髪型などのトップレベルカテゴリを設定（オブジェクトを各オプションにドラッグ）
- **ミックスグループリスト**: 靴、靴下など個別に組み合わせ可能なパーツを設定
- 各アイテム内の **クローズオプション** を展開して細かいパーツ制御

### 3. メニューを生成

Inspector下部の **"生成菜单"**（メニュー生成）ボタンをクリック。生成されるアセット：

- MA Parameters（Expression Parameters）
- MA Menu Installer（VRChatアクションメニュー）
- FX Animator Controller（ステートマシン + Parameter Driver）
- MA Object Toggle / Merge Animator コンポーネント

### 4. アップロード

通常通りアバターをアップロード — メニューは自動的にバンドルされます。「アップロード前に自動再生成」を有効にすると、毎回最新の設定が使用されます。

## 📖 設定詳細

### スーパースイッチグループ

```
服
├── 服A (値=1)  → 服Aオブジェクトをドラッグ
│   ├── デフォルトミックス設定 → 靴=1, 靴下=1
│   └── サブレベルクローズメニュー → リボンを隠す, スカートを隠す
├── 服B (値=2)  → 服Bオブジェクトをドラッグ
└── 服C (値=3)  → 服Cオブジェクトをドラッグ
```

- **現在のアイテムを再クリックでデフォルトミックス復元**: 有効時、服A着用中に再度服Aをクリックすると、LastOp経由で靴/靴下のデフォルト値が復元されます
- **「なし/オフ」を生成**: メニューの先頭に「なし」オプションを追加

### ミックスグループ

```
靴
├── 靴A (値=1) → 靴A + 靴下A コンボをドラッグ
├── 靴B (値=2) → 靴B + 靴下B コンボをドラッグ
└── なし (値=0)
```

- **スーパースイッチオフ時に連動オフ**: 服が「なし」に設定されると、靴も自動的に0になります
- **デフォルトミックス設定** で靴を現在の服の値に自動追従可能

### LastOpの仕組み

LastOp（Last Operation / 最後の操作）はこのプラグインの中核機構です。プラグイン内部で `LW_LastApplied_*` パラメータを使用し、各衣装グループの最後のアクティブ値を記憶します。ユーザーが現在着用中の衣装を再度クリックすると、LastOpが「実際の切り替えは発生していない」と検出し、同じ値の冗長な再適用ではなくデフォルトミックス復元を実行します。これにより、Avatar Parameter Driverで発生しうる組み合わせ状態爆発を回避します。

### 全閉ボタン

- **すべてのパーツを閉じる**: スーパースイッチグループのパーツのみ閉じ、ミックスグループには影響しません
- **カスタム全閉ボタン**: 含めるミックスグループを選択可能（例：「靴＆靴下を含む全閉」）

## 🔍 競合検出

Inspector下部の **"冲突检测 / 配置检查"**（競合検出）で以下をチェック：

- 重複パラメータ名
- 重複パラメータ値（同一グループ内）
- 空のオブジェクト参照
- 未一致のデフォルトミックス設定
- 複数スイッチで制御されているオブジェクト
- 既存MA Object Toggleとの競合の可能性
